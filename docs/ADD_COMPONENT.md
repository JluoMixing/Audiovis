# 添加新组件

一份可执行的清单。按顺序做，每步都写清了**改哪里**、**漏了会怎样**。

---

## 快速版（3 步）

| # | 做什么 | 文件 |
|---|---|---|
| 1 | 新建组件文件，调 `register()` | `src/components/<名>.js` |
| 2 | 重建界面产物 | `python preview/build_gui.py` |
| 3 | 验证 | 打开界面，组件库里应出现该组件 |

**不需要改任何清单** —— `build.py` 会扫 `src/components/` 目录，
新增文件自动被发现（已用 `tools/test_auto_discover.py` 验证）。

**也不需要改 `app.js`** —— 组件库从 `COMPONENTS` 自动生成。

---

## 详细步骤

### 1. 新建组件文件

路径：`src/components/<名>.js`（文件名小写，与 `id` 一致）

```js
/* 组件说明写在这里（会显示在属性面板的说明区，支持 HTML） */
register({
  id: 'mytool',            // 唯一标识，小写无空格
  name: '我的工具',          // 组件库显示名
  w: 420, h: 300,          // 默认尺寸（拖进画布的初始大小）
  group: '音频',            // 分组：内容 / 结构 / 音频 / 信息

  desc: '一句话说明。<b>支持 HTML</b>。',

  // 默认样式（可选）。GUI 属性面板会基于它生成控件。
  默认: {
    // 有 颜色 / 字号 之类的字段时，属性面板自动出现对应控件
  },

  绘制: function (g, w, h, 样式) {
    // g 是 Canvas 2D 上下文，坐标原点是组件左上角
    // w, h 是组件当前尺寸
    // 样式 是用户调整后的样式（含 默认 的兜底）
    g.fillStyle = '#888';
    g.fillRect(0, 0, w, h);
  },
});
```

#### 关于 `register()` 的字段

`src/core/registry.js` 会**校验必需字段**，缺了立即抛错：

```js
const need = ['id', 'name', 'w', 'h', 'draw'];
```

注意：校验的是 `draw`，但实际组件可以写 `绘制`（中文别名）。
两种写法都支持，推荐用 `绘制`（与项目其它代码一致）。

#### 两种绘制路径

| 你的组件 | 用哪个函数 | 说明 |
|---|---|---|
| 位图型（用固定尺寸绘制再缩放） | `draw(g, w, h)` | 组件按注册尺寸画，再 `g.scale()` 到目标尺寸 |
| 矢量型（文字类） | `绘制(g, w, h, 样式)` | 直接在目标尺寸上画，无缩放 |

**文字类组件**额外需要 `测量(样式, 参考宽)`，返回 `{w, h}`：

```js
测量: function (样式, 参考宽) {
  return 测量文字(样式, 参考宽);
},
```

有了 `测量`，组件在布局里就可以**不给 w/h**（自适应尺寸）。
`paint.js` 的 `绘制布局()` 会调它算尺寸 ——
这是模板里文字组件能正常渲染的关键。

#### 可选：主题质感

组件可以用 `src/core/surfaces.js` 提供的包装函数，
自动获得当前主题的质感（不必自己判断主题）：

```js
sFill(g, x, y, w, h, P.ink, 0.8);      // 带主题质感的填充
sStroke(g, x, y, w, h, P.ink, 0.6);    // 带主题质感的描边
sMark(g, x, y, r, P.accent, 1);        // 标记点
sGrid(g, x, y, w, h, P.inkFaint);      // 网格
```

主题没登记 `SURFACE` 时会静默回退到 `sumi` —— 见 `ADD_THEME.md` 的说明。

### 2. 重建

```bash
python preview/build_gui.py
```

只重建界面产物，约 0.5 秒。

### 3. 验证

打开界面（`python run.py`），检查：

- 组件库里出现「我的工具」，分组正确
- 拖进画布，尺寸是 `w × h`
- 属性面板能调样式
- 导出视频里也能看到

## 常见错误

| 症状 | 原因 | 修法 |
|---|---|---|
| 组件库里没有 | 文件不在 `src/components/` 或语法错误 | 检查路径与控制台 |
| 报错 `缺少字段` | `register()` 缺 `id/name/w/h/draw` | 补齐 |
| 拖出来尺寸不对 | 组件库里显示对但拖出来不对 | 检查 `w`/`h` 是否写在 `register()` 里 |
| 导出里没有 | 组件的 `绘制`/`draw` 抛异常被吞 | 看浏览器控制台 |
| 文字组件不显示 | 没有 `测量` 且模板没给 w/h | 加 `测量` |

## 相关文件

| 文件 | 作用 |
|---|---|
| `src/core/registry.js` | `register()` 与 `COMPONENTS` 数组 |
| `src/core/paint.js` | `绘制组件实例()` / `绘制布局()`（GUI 与导出共用） |
| `src/core/surfaces.js` | 主题质感（`sFill` / `sStroke` 等） |
| `preview/gui/js/app.js` | 组件库面板（从 `COMPONENTS` 自动生成） |

---

## 记住这一条

**组件的 `name` / `w` / `h` / `group` 只在 `register()` 里写一次。**

不要在任何地方重复这些数据 —— 重复必然漂移。
（曾经 `app.js` 里有一份手写的 `COMPS` 表，与 `register()` 漂移了 4 项，
导致拖进画布的组件尺寸是错的。）
