Audiovis brand assets
=====================

Files
-----
- Audiovis_logo_vector.svg
  Editable, scalable vector logo. Transparent background. Contains the emblem,
  Audiovis wordmark, and tagline. Open in Inkscape, Illustrator, Figma, or a
  code editor. The font stack is a fallback stack; text may be converted to
  outlines in a vector editor if exact typography must be preserved.

- Audiovis_selected_concept_reference.png
  The selected generated concept image for visual reference. This is a raster
  presentation image, not a clean icon source.

Suggested DSH task
------------------
Use Audiovis_logo_vector.svg as the vector source and
Audiovis_selected_concept_reference.png as the visual reference. Produce a
Windows .ico file for the Audiovis application. Extract/use the emblem only
(no wordmark or tagline) for the app icon. Keep the icon centered with generous
safe margins, transparent background where supported, and a clean silhouette
that remains legible at 16x16 and 32x32. Export a multi-resolution ICO containing
at least 16, 24, 32, 48, 64, 128, and 256 px sizes. Also export a 1024x1024
transparent PNG preview. Do not redesign the logo; preserve the overlapping,
non-identical reflected forms and monochrome silver/gray identity.

Important
---------
The SVG is an editable vector interpretation based on the selected concept,
not an automatic vectorization of every pixel in the concept image. Review the
shape proportions in a vector editor before final production if pixel-level
matching is required.
